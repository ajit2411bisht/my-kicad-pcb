# ESP32-C3 PCB Design

## Overview

This project contains a custom PCB design based on the ESP32-C3.

The PCB was designed using KiCad and includes the main ESP32-C3 circuit along with sensor and user-interface sections.

## Tools Used

- KiCad

## Project Files

- `esp32demoproject.kicad_pro` - KiCad project file
- `esp32demoproject.kicad_pcb` - PCB layout
- `esp32-c3-02.kicad_sch` - ESP32-C3 schematic
- `sensors.kicad_sch` - Sensor section schematic
- `user_interface.kicad_sch` - User interface schematic

## Features

- ESP32-C3 based design
- Sensor interface
- User interface section
- Custom PCB layout
- Hierarchical schematic design

## PCB Design

The PCB layout was designed and reviewed using KiCad.
